# Mitali Nagarse — Portfolio

A responsive static portfolio for Mitali Nagarse, Angular Developer / Software Engineer.

## Files
- `index.html` — portfolio page
- `style.css` — styling

## Publish with GitHub Pages
1. Create a GitHub repository named `mitali-nagarse.github.io`.
2. Upload `index.html` and `style.css`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Your website will be available at `https://mitali-nagarse.github.io/`.

## Before publishing
- Add your GitHub profile URL when available.
- Review the project descriptions and dates.
- Optionally add links to public project demos or repositories.
